# 番茄小说下载器（网页版）—— 群晖 NAS 部署（端口 8084）

按原版「番茄小说下载器」的功能重写的**纯网页版**：不需要虚拟桌面或 VNC，跟媒体下载器一样，
浏览器打开就是中文网页。

- **搜索**：书名 / 作者，或直接粘贴番茄书籍链接、书籍 ID
- **详情**：封面、作者、状态、字数、简介、分卷章节目录，可**预览**任意章节
- **下载**：TXT / EPUB（带封面和目录），可指定章节范围；下载队列、进度、取消、删除
- **断点续传**：已下载章节缓存在 `data/` 里，失败或中断后点「重试」只补缺的章节
- **已下载**：列出下载目录里的文件，可直接下载到电脑 / 手机
- **访问密码**：初始 `123456`，在「设置」里修改

## 跟原版的区别（重要）

原版是冒充番茄手机 App 调接口；这个版本只走**番茄官方网页**（fanqienovel.com），所以：

- ✅ 免费书正常下载（番茄绝大部分书都是免费的）
- ❌ 没有原版的在线阅读器、书架同步、评论、官方账号登录、阅读时长同步
- ⚠️ 付费 / 只给试读的章节，需要在「设置」里填你自己浏览器登录后的 **Cookie**
- ⚠️ 番茄网站改版时可能失效，需要更新代码

### 正文反混淆是怎么做的

番茄网页版的正文用了自定义字体：几百个常用字被替换成了乱码字符，浏览器靠特殊字体显示成正常字。
本程序会自动下载这个字体，把每个乱码字符画成图片，用 **Tesseract OCR**（中文模型）多种画法识别后投票决定真字，
识别结果按字体缓存在 `data/fontmaps/`。番茄换字体时会自动重新识别。

- 每套字体首次识别约 **15 秒～1 分钟**（看 NAS 性能），之后直接用缓存
- 实测识别准确率约 99%，偶尔可能有个别错字（比如 花→化、常→党 这类形近字）
- 发现某个字总是错，可以新建 `data/charmap_override.json` 手动纠正，例如：
  ```json
  { "化": "花" }
  ```
  键也可以写乱码字符本身或 `U+E8E8` 形式的码位。改完立即生效，不用重启。

## 部署步骤（DSM 7.2+，Container Manager）

1. **上传**：File Station 在 `docker` 下新建 `fanqie-web`，把本文件夹内容全部传进去，再建一个空的 `data` 文件夹：
   ```
   /volume1/docker/fanqie-web/
   ├── docker-compose.yml  Dockerfile  requirements.txt
   ├── app/   (app.py + static/index.html)
   └── data/
   ```
   下载目录默认是 `/volume2/downloads/小说`，没有就先建好，或在 compose 里改成你自己的路径。
2. **建项目**：Container Manager → 项目 → 新增 → 选该文件夹 → 用现有 compose → 完成。
   第一次会**构建镜像**（Ubuntu + Python + Tesseract 中文包，apt/pip 都走清华镜像），约 3~5 分钟。
   日志出现 `==> 番茄小说下载器（网页版）已启动` 即就绪。
3. **用**：浏览器打开 `http://群晖IP:8084/`，输入密码 `123456` → 先去「设置」改密码。
4. **自检**：「设置」→「连通性自检」，看到 `番茄网站：HTTP 200`、`OCR 引擎：5.x`、语言里有 `chi_sim` 就没问题。

## 常见问题

- **搜索失败 / 下载大量失败（403）**：被番茄风控了。「设置」里把「同时下载章节数」调成 1、「每章间隔」调到 2 秒，过一会儿再点「重试」。
- **章节只有几行 / 提示需要 Cookie**：这章是付费或只给试读。电脑浏览器登录 fanqienovel.com，F12 → 网络 → 刷新 →
  点任意 fanqienovel.com 请求 → 复制请求头里整行 `Cookie` 粘到「设置」里保存，再「重试」。
- **正文里有乱码方块或个别错字**：「设置」里「清除字体识别缓存」后重新下载；个别字用 `charmap_override.json` 纠正。
  注意已下载的章节会用缓存，想要重新识别要删除 `data/cache/<书籍ID>/` 文件夹后再重试。
- **端口冲突**：改 compose 里 `"8084:8084"` 左边的数字。
- **更新代码**：替换 `app/` 文件夹后，Container Manager 里项目「停止 → 构建 → 启动」。

## 文件说明

| 文件 | 作用 |
|---|---|
| `app/app.py` | 后端：番茄网页接口、字体 OCR 反混淆、下载队列、TXT/EPUB 导出 |
| `app/static/index.html` | 中文网页界面（手机也能用） |
| `Dockerfile` / `requirements.txt` | Ubuntu 24.04 + Python + Tesseract 中文 + Noto 中文字体 |
| `data/` | 设置、密码、任务记录、章节缓存、字体识别缓存 |

## 安全提醒

只在家庭内网 / VPN 使用，不要把端口转发到公网；填了 Cookie 等于把你的番茄账号交给了这个程序。
下载内容仅供个人阅读，遵守番茄小说服务条款，不要传播。
