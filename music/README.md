# 媒体下载器（两合一）—— 群晖 NAS 部署版（端口 8083）

把之前的**网易云音乐下载器**和 **B站/YouTube 视频音频下载**合并成了一个容器、
一个网页、一个下载目录。顶部两个标签页切换：

- **网易云音乐**：扫码登录 → 搜索 → 下载（标准/320k/无损）；.ncm 文件自动转 FLAC
- **视频/音频下载**：粘贴 B站/YouTube 链接 → 选「原始最佳音频 / MP3 320k / FLAC / 最高画质视频」→ 下载

下载的文件都进同一个 `downloads` 文件夹，下载任务在同一个队列里显示。

## 访问密码

打开网页会先要求输入**访问密码，初始 `123456`**。进入后点右上角 **🔒 修改密码**
可自行更改（需先输入当前密码，新密码至少 4 位）。密码存在 `data/` 里，重启不丢；
改密码后其它已登录的浏览器会失效需重新输入。

## 文件说明

| 文件 | 作用 |
|---|---|
| `docker-compose.yml` | 免构建：官方 python 镜像 + 启动时装 ffmpeg / yt-dlp / 网易云依赖 |
| `app/app.py` | 后端：网易云接口 + yt-dlp 下载，统一任务系统 |
| `app/static/index.html` | 全中文双标签网页 GUI |
| `downloads/` | 下载目录 | `data/` 网易云登录态 | `cookies/` 可选登录 cookie |

## 部署步骤（DSM 7.2+，Container Manager）

1. **上传**：File Station 在 `docker` 下新建 `media-downloader`，把本包内容全部传进去：
   ```
   /volume1/docker/media-downloader/
   ├── docker-compose.yml
   ├── app/  (app.py + static/)
   ├── downloads/   data/   cookies/
   ```
2. **建项目**：Container Manager → 项目 → 新增 → 选该文件夹 → 用现有 compose → 完成。
3. **等首启**：第一次要下 python 镜像 + 装 ffmpeg 和依赖，约 **2~4 分钟**（比之前久，因为多了 ffmpeg）。
   日志出现 `==> 媒体下载器已启动` 即就绪。
4. **用**：浏览器打开 `http://群晖IP:8083/`。

> 每次容器启动会重装一遍依赖（约 1~3 分钟）。好处是 **yt-dlp 每次都是最新版**——B站/YouTube
> 经常改版，最新版适配最好，等于自动保持可用。

## 两个功能怎么用

**网易云音乐**：切到该标签 → 手机 App 扫码登录 → 搜索 → 点「↓ 下载」。
只能下你账号有权限的歌，VIP/无版权会提示无法下载。

**视频/音频下载**：切到该标签 → 粘贴链接 → 选模式 → 「添加下载」。
- **原始最佳音频**（推荐）：抓源站最高码率音频流，音质最高、不转码（YouTube 多为 opus/m4a，B站多为 m4a）。
- **MP3 320k / FLAC**：用 ffmpeg 统一转码成对应格式。
- **最高画质视频**：下最高清晰度并合成 mp4。

## B站会员登录（下载会员/高清内容）

在「视频/音频下载」标签页顶部：

1. 点 **「扫码登录 B站」** → 弹出二维码；
2. 手机 B站 App → 我的 → 右上角扫一扫 → 确认登录；
3. 显示「B站已登录：昵称（大会员）」即成功。

之后下载会员专享、1080P+/大会员音质等内容就会用你的登录身份。登录态保存在 `data/`，
重启容器不用重新扫码；右上角可「退出 B站」。

> 用的是 B站 TV 端官方扫码接口（带签名），解决了之前网页版「签名错误」的问题。

## YouTube 登录（一般不需要）

YouTube 绝大多数视频**无需登录**即可下载。只有会员专享、年龄限制等内容才需要：
点「视频/音频下载」标签页里的 **「上传 cookies.txt」**，选择用浏览器扩展
（如 “Get cookies.txt LOCALLY”）在已登录 YouTube 页面导出的 `cookies.txt` 即可。

> YouTube/Google 没有二维码登录方式，所以用 cookies.txt。B站 与 YouTube 的登录互不影响，
> 程序会自动把两边的 cookie 合并给下载器使用。

## NCM 文件自动转 FLAC

网易云官方客户端下载的加密 `.ncm` 文件，**放进 `downloads` 文件夹即可自动解密**成
原始的 FLAC 或 MP3（约 20 秒内自动扫描一次；也可在「网易云音乐」标签页点「立即扫描转换」
马上处理）。转换成功后原 `.ncm` 会被删除，得到的 FLAC/MP3 带歌曲信息和封面。

> 原理与 https://convert.freelrc.com/NCM-to-FLAC 相同：NCM 内部本就是 FLAC/MP3，
> 解密即得原文件，不做二次转码，音质无损。源文件是 FLAC 就输出 FLAC，是 MP3 就输出 MP3。

## 常见问题

- **端口 8083 占用**：改 compose 里 `"8083:8083"` 左边的数字。
- **首次启动久 / 卡在装依赖**：apt 和 pip 已走清华镜像，正常 2~4 分钟；网络差可多等一会。
- **视频下载失败**：多为需登录（加 cookies）或站点临时改版（重启容器会拉最新 yt-dlp）。
- **网易云搜索/登录报错**：网易云风控，等 10~30 分钟或重新扫码。
- **下载的文件在哪**：NAS 上 `media-downloader/downloads`，File Station / SMB / Audio Station 可访问。

## 安全提醒

8083 端口无密码，登录的是你自己的账号——只在家庭内网 / VPN 使用，不要转发到公网。
下载内容仅供个人使用，遵守各平台服务条款。
